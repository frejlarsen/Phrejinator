# Introduction

This repository presents a pipeline for preparing and analysing virome data. 

The pipeline is a continuation of the pipeline started by Josue Castro. The original pipeline can be viewed at his repo at https://github.com/jcame/virome_analysis-FOOD.

Additionally, the pipeline uses parts from Shiraz Shah's pipeline, which can be viewed at https://github.com/shiraz-shah/VFCs.

The pipeline has been used for the analysis of viromes from 700 infants from the COPSAC cohort (pending publication).
